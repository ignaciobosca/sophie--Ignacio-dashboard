# Amazon Listing Compliance Keywords Reference Table

## How to use this table (read before screening copy)

This is the master list of words/phrases Amazon restricts. Screen **all** brand-story copy
(headlines, body, Q&A answers, About Us, section headings) against it before finalizing the plan.

**Reading the matrix:** `TRUE` means the keyword is **restricted / likely to flag** in that
column's context. `FALSE` means it's not flagged there.

**Which columns apply to a Brand Story:** Brand Story lives in A+ content, and card imagery
carries embedded text. So check these columns:
- **A+ Basic** and **Infographics and A+ Premium** (the format columns that apply), AND
- the seller's **product category** column (e.g. *Beauty and personal care*, *Pet supplies*,
  *Home and kitchen items*). Ask for the category during the interview if it isn't obvious.

**The rule:** if a word in the copy is `TRUE` for *either* applicable format column *or* the
seller's category column, treat it as restricted — rewrite the copy to avoid it, and note the
swap. When genuinely unsure whether a match applies, err toward removing/replacing the term;
a slightly blander line is cheaper than a suppressed listing.

Match on word stems and spacing variants (the table already lists many, e.g. "Anti-bacterial /
Anti bacterial / Antibacterial"). Symbols like ™, ®, and $ are also flagged in A+ contexts.
