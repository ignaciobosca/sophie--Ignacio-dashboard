# Seller Central Field Map (Phase D)

Read at Phase D when the seller is pasting copy into the live Seller Central listing editor (they share screenshots or ask where things go). Walk each tab in on-screen page order. For every field: give the exact value, check off correct ones, flag mismatches, mark skips. State once: "I'm mapping fields, not advising on your price."

## Product Details tab (top to bottom)

| Field | What to enter | Notes |
|---|---|---|
| Customizations | No | Unless truly customizable |
| Item Name | the drafted title | **75-char hard cap** (all categories except media). Over-length titles get auto-rewritten by Amazon AI. Structure: brand, product type, one top keyword. Replaces the live title only on Save. |
| Item Highlights | comma-separated phrases | NEW field, sits right under Item Name. Up to 125 chars. Comma-separated phrases, not sentences (e.g. "USB-C rechargeable, 112 cards, ages 1-7, travel toy"). Searchable, shows under the title in search + on the PDP. Put the secondary terms displaced from the title here. Do NOT paste the old long title in. |
| Brand Name | exact brand | CHECK SPACING consistency vs title (e.g. "Acme Goods" vs "AcmeGoods"). Pick one, match everywhere. Note: the page header keeps showing the OLD title until Save. |
| External Product ID (UPC) | locked, leave | |
| Item Type Keyword | category leaf | usually locked/pre-set |
| Target Audience Keyword | e.g. Unisex Children | |
| Model Name | model | |
| Manufacturer | brand or factory | |
| Product Description | CLEAN plain text | Strip em-dashes and HTML. Amazon strips most HTML now; plain text is safer. |

## Offer tab

Mostly seller-owned pricing/fulfillment. Do NOT advise on price points.
- SKU, Product Type, Condition (New), Shipping Template: usually pre-set, check.
- Quantity, Handling Time, Your Price, List Price: seller's numbers, leave as set.
- **Gift Options (Gift Messaged / Gift Wrap):** set **Yes** if the listing positioning leans on gifting AND fulfillment supports it (FBA handles wrap automatically; FBM means you wrap). Adds the gift checkbox to the detail page.
- **Maximum Order Quantity:** optional; some cap at 3-5 early in a launch.
- **Item Package Dimensions + Package Weight:** fill for correct shipping/FBA fees. Use the CARTON measurements and weight, NOT the device specs.
- **Supplemental Condition Information** (Battery Life %, Cosmetic, Functional Condition, Packaging, Source Type): skip entirely for a New item.
- **MAP / Min-Max Seller Allowed / Sale Price / Sale dates:** optional, leave blank unless running a scheduled sale or enforcing MAP.
- **Product Tax Code:** optional, Amazon defaults if empty.
- **Manage offers in other marketplaces (Canada/Brazil/Mexico):** leave OFF for an English-only US listing. Toggling on auto-translates the copy and can mis-render Spanish backend terms.

## The stale-cache reminder
Always tell the seller: the page header (and the "live" title shown across tabs) keeps showing the OLD title until they click Save and finish on Product Details. Confirm the new title actually saved there.
