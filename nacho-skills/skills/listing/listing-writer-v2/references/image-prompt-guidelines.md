# Image Prompt Guidelines (Tab 3 AI Image Prompt column)

Fills the `AI Image Prompt` column with a ready-to-paste prompt for ChatGPT or an image model. Each prompt bakes in the Amazon guideline for that specific slot. The seller pastes the prompt, generates or mocks the image, then hands it to a photographer/designer as a reference. Generated images are concept references, real product photography is still required for the main image on a live listing.

## Amazon image rules to encode

### Main image (slot 1) — strict, non-negotiable
- Pure white background, RGB 255, 255, 255 (Amazon replaces near-white with true white; ask for true white to avoid grey halos).
- Product fills 85% or more of the frame.
- The actual product only. No text, no logos (except on the product), no watermarks, no badges, no inset images, no props, no accessories not in the box.
- No mannequins for most categories; flat-lay or product-only.
- Professional photo, in focus, realistic color. No drawings or CGI for the main image on a live listing (CGI mockups are fine as a planning reference only).
- Whole product in frame, not cropped.

### Secondary images (slots 2-7) — flexible
- Lifestyle, infographic, scale shots, in-use, packaging, comparison, feature call-outs all allowed.
- Text and graphics allowed.
- Should each answer one shopper question or cover one COSMO dimension.
- Keep claims consistent with the copy (no new unsupported claims in images).

## Prompt template per slot

Build each prompt as: subject + composition + the Amazon rule for that slot + style. Examples (generic, fill brackets from intake):

- **Hero / main:** "Product photography of [product] on a pure white seamless background (RGB 255,255,255, true white, no grey). The product fills about 85 percent of the square frame, centered, sharp focus, even soft studio lighting, realistic color, no shadows bleeding into the edges. Show the complete product with [key included components]. No text, no logos, no props, no extra objects. Professional e-commerce catalog style."
- **Scale / size (slot 2):** "Lifestyle photo showing [product] held in a [target user]'s hands (or next to a common reference object) so the real size reads instantly. Include a clean size callout graphic with dimensions [LxW]. Bright, natural setting. This answers the top return driver: size confusion."
- **How it works (slot 3):** "Clean 3-step infographic on a light background showing [step 1] then [step 2] then [step 3], with simple numbered panels and short labels. Product shown clearly in each step. Modern, uncluttered, parent-friendly."
- **Features / variety (slot 4):** "Flat-lay or grid showing [the range, e.g. all components/variants/categories], with a bold headline callout of the key number [e.g. 224 words]. Organized, colorful, easy to scan."
- **Materials / safety / specs (slot 5):** "Infographic with an icon row for [feature 1], [feature 2], [feature 3], on a clean background, product shown beside the icons. No medical or unverified claims. Calm, trustworthy palette."
- **Durability / quality (slot 6):** "Close-up macro of [the durability feature, e.g. rounded corners, reinforced seams, coated surface], shallow depth of field, emphasizing build quality. Optional subtle drop or stress visual. Premium feel."
- **Gift / lifestyle (slot 7):** "Warm lifestyle photo of [target user] using [product] in [use scenario, e.g. car, restaurant, home], natural light, candid mood. Optional gift-wrap or occasion cue. Aspirational but realistic."

## Rules for writing the prompts
- Pull every bracket value from intake; never invent product facts (Rule 1 still applies inside prompts).
- The main-image prompt ALWAYS includes the pure-white + 85% + no-text constraints verbatim.
- Never put an unverified or non-compliant claim into a prompt (e.g. no "FDA approved", no medical/therapy text on a toy).
- Keep prompts one short paragraph each, paste-ready, plain language.
