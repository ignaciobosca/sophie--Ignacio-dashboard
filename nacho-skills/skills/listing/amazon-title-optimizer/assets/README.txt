Optional branding asset for the PowerPoint cover slide.

Drop the Sophie Society logo here as one of (checked in this order):
  sophie-society-logo.png
  sophie-logo.png
  logo.png
  sophie-society-logo.jpg
  logo.jpg

If a logo file is present, build_pptx.py places it on the cover slide.
If none is found, the cover falls back to a "SOPHIE SOCIETY" text wordmark.

A transparent-background PNG, roughly 600-1200 px wide, looks best on the
navy cover. The script scales it to ~1.35 in tall and centers it.
